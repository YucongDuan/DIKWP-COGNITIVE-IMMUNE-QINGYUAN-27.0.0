# DIKWP 主动认知免疫与现实修复系统 / QINGYUAN 27.0.0（清源）

> 不清除负面情绪，清除利用情绪获利的操纵机制；不压制坏消息，修复其证据与语境；不把人标成坏人，约束可验证的有害行为与放大机制。

QINGYUAN 27.0.0 是一个离线优先、个人可直接使用的研究原型，用于识别和主动削弱：虚假事实、难以验证却被包装成知识的内容、语境截断、身份压力、零和关系叙事、成瘾设计、脆弱群体定向诱导、隐蔽销售漏斗，以及已经造成的可验证现实伤害。

它同时保护：批评、举报、科学反例、悲伤、痛苦表达、受害者陈述、事实性坏消息和求助信息。

## 核心输出

系统不输出一个“正能量／负能量善恶分”，而输出十个维度：证据完整、语境完整、操纵压力、成瘾压力、利益不透明、脆弱性利用、关系外部性、伪知识风险、可纠正性和已观察伤害。

## 快速开始

```bash
python -m pip install -e .

```

也可以直接打开 `release/QINGYUAN_Personal_Cognitive_Immunity_Client_27.0.0.html`。
