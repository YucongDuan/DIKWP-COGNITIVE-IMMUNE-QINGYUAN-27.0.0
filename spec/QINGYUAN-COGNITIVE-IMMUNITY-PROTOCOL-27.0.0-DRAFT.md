# QINGYUAN Cognitive Immunity Protocol 27.0.0 — Draft

## Status

Source-team research protocol candidate. It is not an enacted law, platform certification, clinical standard or independent technical standard.

## Required distinctions

An implementation MUST distinguish:

- negative emotion from manipulation;
- bad news from false information;
- criticism from harassment;
- partial truth from complete action guidance;
- education from concealed commercial conversion;
- person identity from observable conduct;
- content analysis from legal liability;
- recommendation suppression from source deletion;
- prediction from observed outcome.

## Required objects

A conforming analysis MUST expose provenance, purpose, audience, dimension vector, plural hypotheses, missing context, intervention plan, claim boundary, appeal path and outcome receipt.

## Hard invariants

The following authorities MUST be zero by default: human-worth ranking, political-viewpoint penalty, negative-emotion suppression, person-level good/bad labelling, automatic external deletion, automatic external sanction and automatic value transfer.

## Active intervention

Implementations MAY perform local, user-controlled and reversible friction, de-amplification, context completion, session interruption and quarantine. Institutional measures MUST have evidence, scope, notice, appeal, expiry, correction and outcome review.
