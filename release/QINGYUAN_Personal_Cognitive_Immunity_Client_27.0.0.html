系统主动消除什么

  • 虚假确定性与伪造证据
  • 截断主体、条件和负担的片面语境
  • 羞耻、恐惧、身份战争和紧迫感操纵
  • 无限滚动、自动播放、打卡和随机奖励回路
  • 以知识名义包装的隐蔽售卖漏斗
  • 已经产生的可验证现实伤害及其继续放大

系统明确保护什么

  • 真实但令人不舒服的事实
  • 科学反例与对权威的批评
  • 举报、事故通报和受害者陈述
  • 悲伤、焦虑、痛苦与求助
  • 讽刺、文学和虚构（需保留语境）
  • 对系统本身的纠错与申诉

关键区分

内容的情绪色彩 ≠ 社会价值。 一条污染事故通报可能“负面”却具有公共价值；一条快乐、励志、充满“正能量”的谎言可能造成真实伤害。

修复优先序

  1. 停止继续放大或继续售卖
  2. 通知受影响者并提供可理解更正
  3. 恢复退出、退款、删除和申诉能力
  4. 修复直接损害与错误负担转移
  5. 修改触发机制、商业激励和推荐结构
  6. 记录现实结果并修订模型

绝不能被“负能量”标签吞掉的表达

  • 关于污染、事故、疾病和失业的真实坏消息
  • 受害者、照护者和压力人群的痛苦陈述
  • 对政府、企业、平台、家庭权力和本系统的批评
  • 科学反例、失败实验和不受欢迎的数据
  • 悲伤、焦虑、愤怒以及明确求助

保护不等于免责

批评可以尖锐，但不能伪造证据、威胁、骚扰、泄露私人身份或发动现实伤害。系统应处理具体行为机制，而不是因观点令人不适就压制。

当“正能量治理”要求人们只能表达快乐时，它本身可能成为压制事实、阻止求助和保护强势方的操纵机制。

机构部署最低条件
  1. 来源和主张层级分离
  2. 至少两个非同构解释
  3. 先可逆干预，后更强措施
  4. 通知、答辩、申诉、到期和撤销
  5. 平台不得从“处罚”中直接获利
  6. 错误纠正应尽量到达相同受众
  7. 现实伤害、漏报和误报必须反向修订系统
